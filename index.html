Formula Sheet

Quick reference for exams.

Functions

Linear: y = mx + c
Quadratic: y = ax² + bx + c
Turning point: x = −b / (2a)
Exponential: y = abˣ
Hyperbola: y = a/x + q

Differentiation

d/dx [xⁿ] = n xⁿ⁻¹
Product rule: (uv)′ = u′v + uv′
Quotient rule: (u/v)′ = (u′v − uv′) / v²
Stationary points: set dy/dx = 0

Sequences & Series

Arithmetic: Tₙ = a + (n−1)d
Sₙ = n/2 [2a + (n−1)d]
Geometric: Tₙ = arⁿ⁻¹
Sₙ = a(rⁿ − 1)/(r − 1)
S∞ = a/(1 − r) (|r| < 1)

Financial Maths

Compound: A = P(1 + i)ⁿ
Future Value Annuity: F = x[((1+i)ⁿ − 1)/i]
Present Value Annuity: P = x[(1 − (1+i)⁻ⁿ)/i]

Analytical Geometry

Distance: d = √[(x₂−x₁)² + (y₂−y₁)²]
Gradient: m = (y₂−y₁)/(x₂−x₁)
Midpoint: M = ((x₁+x₂)/2 , (y₁+y₂)/2)

Probability

P(A) = favourable / total
Independent: P(A and B) = P(A) × P(B)
Mutually exclusive: P(A or B) = P(A) + P(B)

Newton’s Laws & Forces

Fnet = ma
Weight: W = mg

Momentum & Impulse

p = mv
Impulse = FΔt = Δp
m₁u₁ + m₂u₂ = m₁v₁ + m₂v₂

Work, Energy & Power

W = FΔx cosθ
Eₖ = ½mv²
Eₚ = mgh
P = W/Δt = Fv

Electric Circuits

V = IR
Series: R = R₁ + R₂ + ...
Parallel: 1/R = 1/R₁ + 1/R₂ + ...
P = VI = I²R = V²/R

Waves

v = fλ
T = 1/f
